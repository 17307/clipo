# Clipo

Paste 风格的 macOS 剪贴板管理器 —— 屏幕底部横向卡片轮播，基于 SwiftUI + SwiftData 构建。

凡是你复制过的东西都变成一张卡片。按 `⇧⌘V` 唤出，方向键浏览历史，按 `⏎` 粘贴回原来的 app。

[English README](./README.md)

## 特性

- **底部横向轮播** —— 全屏宽度半透明面板，220pt 卡片网格，`⇧⌘V` 从屏幕底缘滑入
- **文本 / 图片 / 文件 / 网址 / 颜色** —— 每种类型有专门的卡片内容区
- **拖出到外部 app** —— 卡片可以直接拖进 Finder / 编辑器 / 浏览器 / 聊天工具。文件拖的是原 URL（不复制），文本/图片/颜色只在真正 drop 时才懒加载到临时文件
- **多选 + 批量粘贴** —— `Shift`-点击连选、`⌘`-点击单选切换，`⏎` 按你点击的顺序依次粘贴
- **Pinboards 收藏板** —— 自定义命名板（代码片段 / 常用短语 / 报表模板…），每个板独立 accent 色。`⌘P` 把当前项移入，`⌘1-9` 在 tab 间切换
- **搜索** —— 精确 / 包含 / 模糊三种模式，匹配关键字内联高亮
- **图片 OCR** —— 截图自动识别文字、纳入搜索索引（Vision 框架、后台线程）
- **脚本** —— 用户自定义 JavaScript 变换（去空白、美化 JSON、URL 解码…），在卡片右键菜单里出现
- **忽略规则** —— 按 app、按 pasteboard 类型、按正则表达式三个维度过滤，把密码和敏感数据挡在历史之外
- **`clipocli` 命令行工具** —— 随 app 一起安装，便于脚本和 shell 调用

## 系统要求

- macOS 14 Sonoma 或更新
- 需要辅助功能权限（Accessibility），用于向前台 app 注入 `⌘V`

## 安装

### 下载 DMG

从 `build/` 目录拿 `Clipo-0.1.0.dmg`，把 `Clipo.app` 拖进 `/Applications`，首次启动按提示授予辅助功能权限。

### 从源码编译

```bash
# 生成 Xcode 项目（使用 XcodeGen，没有的话 brew 装一下）
brew install xcodegen
xcodegen

# Debug 构建
xcodebuild -project Clipo.xcodeproj -scheme Clipo -configuration Debug build

# Release + DMG
bash scripts/build-release.sh
bash scripts/make-dmg.sh
open build/Clipo-0.1.0.dmg
```

## 快捷键速查

| 快捷键 | 作用 |
|---|---|
| `⇧⌘V` | 打开 / 关闭面板 |
| `← →` | 切换卡片 |
| `⏎` | 把当前卡片粘贴到前台 app |
| `Space` | 打开预览 |
| `⌥1–⌥9` | 快速粘贴当前可见的第 N 张卡片 |
| `⌘1–⌘9` | 切换 filter / pinboard tab |
| `Shift`-点 / `⌘`-点 | 扩展 / 切换多选 |
| `⌘A` | 全选当前可见卡片 |
| `⌫` | 删除当前（或多选批量删除） |
| `Esc` | 关闭面板（先清多选，再按一次才关） |
| `⌘,` | 打开设置 |
| `⇧⏎` | 粘贴为纯文本 |
| `⌥⏎` | 把选中卡片重新写回系统剪贴板 |
| `⌥⇧⏎` | 保留格式粘贴 |

所有热键可在 设置 → General 里重新绑定。

## 架构

- **UI**：100% SwiftUI，承载在无边框 `NSPanel` 里，贴着屏幕底缘
- **数据**：SwiftData 单 `ModelContainer`，文件位于 `~/Library/Application Support/Clipo/Storage.sqlite`
- **剪贴板引擎**：`NSPasteboard.changeCount` 轮询（默认 0.5s，可配置），类型白名单，内部 marker 防止粘贴回环
- **粘贴**：`CGEvent` 注入 `⌘V` 到前台 app（参考 Maccy 的做法）
- **脚本**：`JavaScriptCore` 沙箱，每次调用 500ms 超时，每个脚本独立 `JSContext` 做隔离
- **拖出**：SwiftUI `.onDrag` + `NSItemProvider.registerDataRepresentation` 懒加载 file-URL；拖拽真正开始后面板瞬时隐藏，避免半透明窗口合成吃掉帧率
- **搜索**：[Fuse-swift](https://github.com/krisk/fuse-swift) 做模糊匹配，逐键输入有去抖

### 目录结构

```
Clipo/
├── App/             # AppDelegate、状态栏、拖拽生命周期
├── Clipboard/       # ClipboardEngine、Paster、辅助功能授权
├── Hotkeys/         # 全局 + 窗口内快捷键注册
├── IPC/             # clipocli 桥接（Unix socket server）
├── Models/          # ClipItem、ClipContent、Pinboard（SwiftData）
├── Scripts/         # JS 脚本运行时 + 内置示例
├── Settings/        # 7 个偏好设置 pane
├── State/           # AppState（@Observable、绑在 MainActor）
├── Storage/         # SwiftData ModelContainer
└── UI/              # 面板、轮播、卡片、设计 tokens
```

## 隐私

- 所有数据在本地。无网络请求、无遥测、无 iCloud 同步。
- 历史数据全部存在 `~/Library/Application Support/Clipo/Storage.sqlite`。
- 被 pasteboard 标为 `.concealed` 或 `.autoGenerated` 的条目（密码管理器、Keychain 等）自动跳过。
- 在 设置 → Ignore 里可以按 app / 正则再手动排除特定来源。
